The previous version still treated “specimen” mostly as a CSS class name. Seven partitioned bars sat above an unrelated modern daily table, forcing readers to match the same days across two separate systems. The miniature temple roof belonged to the logo, not the page. Hatching and pin dots supplied period atmosphere, but the visual hierarchy remained an ordinary dashboard with historical stationery laid over it.

This pass commits the structure to a single collection drawer. Each day now has one vertical compartment: plotted quantity above, catalogue heading and exact visits, signups and rate immediately below. The graph and ledger share column boundaries. The separate daily-record panel is removed, preserving every daily figure while removing the duplicated layout. Weekly totals remain prominent above the drawer. Source comparisons form one broad catalogue plate below, with visit bars directly attached to source labels.

The tiny roof is removed rather than supplemented with more Greek ornament. Classical inscription type, the centered winged Psyche engraving and the doubled rules now belong to the actual cabinet title and plates. The winged figure is the single mythic/insect visual connection; no unrelated insect or new mythological section names compete with metric labels. Hatching is restrained to measured bars. Source bars gain usable width instead of being token decorations.

On narrow screens the seven-day collection scrolls as one focusable region, retaining legible aligned columns instead of shrinking all figures into tiny type. This is a deliberate tradeoff: comparing the whole week may require horizontal scrolling, but all records remain available and the rest of the page fits the viewport. Pressed metric states, zero-based proportional bars, keyboard focus, source counts and the shared rate calculation are preserved. This revision is based on source inspection, not a rendered browser check.
